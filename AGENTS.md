# AGENTS.md

## Cursor Cloud specific instructions

This repository is the GitHub "hello-world" tutorial repo. It contains only `README.md`
and has **no application code, no package manifests, no lockfiles, no build system,
no tests, and no lint configuration**.

- There is nothing to install, build, or run. Do not spend time searching for a
  package manager, dev server, or service to start — none exist.
- The only meaningful workflow here is the documentation/git flow: edit `README.md`,
  commit, push, and open a pull request.
- The startup update script is intentionally a no-op.
