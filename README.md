# 超级帽侠 Super Cap Quest

一款面向手机浏览器的原创像素平台跳跃游戏，玩法向经典 8-bit 过关游戏致敬：**跳跃踩怪、问号砖、水管、金币、变身与喷火**。

角色、关卡、音乐和音效均为原创，不使用任天堂的精灵图、旋律或采样。

## 怎么玩

手机试玩（单文件页面，点开即可）：

https://htmlpreview.github.io/?https://github.com/sunhj-cn/hello-world/blob/cursor/super-plumber-mobile-game-af84/play.html

也可以下载仓库里的 `play.html`，用浏览器直接打开。本地开发可用：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。也可把整份项目放到 GitHub Pages 或任意静态托管上。

### 操作

| 操作 | 触屏 | 键盘 |
| --- | --- | --- |
| 左右移动 | ◀ ▶ | ← → / A D |
| 下蹲 / 进水管 | ▼ | ↓ / S |
| 跳跃 | A | 空格 / Z / K / ↑ |
| 加速 / 喷火 | B | Shift / X / J |
| 暂停 | START | Enter / P |
| 静音 | ♪ | M |

按住 **B** 助跑可以跳得更远。吃到火花后按 B 喷火。站在特殊水管上按 **▼** 可进入金币密室。

## 规则

- 3 条命，踩扁行走怪和绿壳怪得分
- 问号砖里可能有金币、蘑菇、火花、星星或 1UP
- 变身后顶碎砖块；受伤会变回小个子，再受伤则失去一条命
- 通关旗杆后会把剩余时间折成分数
- 共 3 关：`1-1 草原出发`、`1-2 地下通道`、`1-3 云端跳跃`

## 技术

纯前端，无构建步骤：Canvas 像素绘制 + Web Audio 合成 8-bit 音效/配乐 + 触屏虚拟按键。
